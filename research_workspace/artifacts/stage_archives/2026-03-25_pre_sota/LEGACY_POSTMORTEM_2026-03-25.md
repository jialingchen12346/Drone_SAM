# 旧研究失败复盘（legacy_2026-03-23）

## 1. 复盘范围

- 归档目录：`/home/jl/Drone-SAM-Adapter/archive/legacy_2026-03-23`
- 核心文档：`论文初稿.md`、`论文草稿.md`、`SESSION_SNAPSHOT.md`、`SOTA_TRACKER.md`、`EVIDENCE_CHAIN.md`
- 原始结果：`work_dirs/work_dirs/v5_ablation_*/eval_test_epoch60.log`
- 决策证据：`archive/.../research_workspace/DECISIONS.md`

## 2. 关键现象（为什么当时“看起来很好”）

1. 旧叙事主结果为 `68.62`，并宣称超过 MM-SAM-Adapter `66.10`。  
2. 同一归档内已出现自我纠偏：`68.62 > 66.10` 不能作为严格主结论（见旧 `DECISIONS.md`）。  
3. 旧评测日志中 `Bicycle` 为 `nan`（test 缺失类），mIoU 由 `nanmean` 计算，实际是 present-only。  
4. 当前主线严格口径（absent=0）重评后，高分普遍明显回落（例如 `67.67 -> 62.84`）。

## 3. 根因分析（按影响排序）

### A. 指标口径漂移（最高影响）

- 证据：
  - 旧评测日志：`Bicycle : nan`（`eval_test_epoch60.log`）。
  - 旧脚本：`np.nanmean(iou)`（`scripts/quick_ablation_eval.py`、`scripts/ablation_bn_calib.py`）。
  - 旧决策明确写出：`68.62` 为 13 类均值，若缺失类按 0 计入约为 `63.72`。
- 影响：
  - 直接导致“相对 SOTA 提升”被高估，论文主结论不稳。
- 结论：
  - 旧路线失败首先不是“模型完全无效”，而是“主结论统计口径不可发表”。

### B. 训练/评测协议不统一（高影响）

- 证据：
  - 大量流程绑定 `epoch_60` 固定点（`run_v5_ablation_queue.py`）。
  - 存在跨机器结果差异约 2 mIoU（旧 `SESSION_SNAPSHOT.md` 已承认）。
  - 旧文稿中混合了不同机器/环境背景数字。
- 影响：
  - 指标可比性和可复现性下降，审稿风险高。

### C. 实验决策偏“结果先行”（中高影响）

- 证据：
  - 写作与图表先围绕高分展开，后补口径说明。
  - “主结果-消融-叙事”耦合到旧 run 标识（`v5/v7` 时代资产）。
- 影响：
  - 一旦口径修正，整条论文故事需要整体回滚。

### D. 自动化治理缺失（中影响）

- 证据：
  - 旧阶段没有强制输出双口径/双 split 的统一模板。
  - 缺少“口径红线”门禁，导致历史高分持续污染后续判断。
- 影响：
  - 研发效率下降，重复试验增加。

## 4. 可保留资产 vs 必须淘汰资产

### 可保留（继续复用）

1. 问题定义框架：条件感知融合 + 小目标/细结构恢复。
2. 工程资产：训练与评测脚本框架、消融组织方式、可视化链路。
3. 论文素材：章节结构、图表模板、失败案例展示方法。

### 必须淘汰（禁止直接沿用）

1. 任何未经 strict(absent=0) 重评的高分结论。
2. 混合环境数字（4070Ti/5090、不同 PyTorch）直接并排对比。
3. 只看 `val` 或只看单口径的晋级逻辑。

## 5. 复盘后硬约束（执行红线）

1. 结果汇报必须同时给出：
   - `split=val` + `split=test`
   - `strict(absent=0)` + `present-only`（present-only 仅作参考）
2. 论文主表只允许 strict 结果。
3. 历史 run 若未 strict 重评，禁止进入主结论。
4. 所有对比必须注明：
   - checkpoint 选择规则
   - 评测 resize 方式
   - 缺失类处理策略

## 6. 对当前主线的直接行动

1. 旧路线定位为“经验库”，不再作为结果事实来源。  
2. 新主线以可复现强基线（MM-SAM-Adapter 思路兼容实现）继续推进，严格口径优先。  
3. 结构迭代采用“单变量快筛 -> 晋级长训 -> strict 固化”的漏斗流程。  

## 7. 一句话结论

旧研究失败的本质是“评测口径与证据治理失败”，不是“任务方向失败”；方向可继承，结论必须重算，流程必须加门禁。

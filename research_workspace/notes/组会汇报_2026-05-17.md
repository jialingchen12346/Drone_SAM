# 组会汇报 · 2026-05-17

## 我们在做什么

一句话：**用很少的标注（10% mask）+ 大量无标签 RGB-T 图像 + SAM2 预训练，做 FMB 语义分割。**

动机很朴素——像素级标注太贵了，但 RGB-T 图像本身不难采。如果 SAM2 见过足够多的自然图像，这个先验能不能弥补标注的不足？同时 RGB 和 Thermal 看到的"不太一样"，能不能让它们互相纠错？

## 怎么做的

协议是 **r10**：只给 10% 的 dense mask，剩下 90% 图像只有 RGB-T 和每类随机一个点。

模型结构：

```
RGB ──→ SAM2 Hiera-L (冻住，只训 Adapter) ──→ ┐
                                                ├──→ MMSA + AGF 融合 ──→ 主预测
Thermal ──→ ConvNeXt-Tiny (全训) ────────────→ ┘         │
                                                          ↓
                                              Disagreement Refinement
                                              （分歧区域残差修正）
```

三个关键想法：
1. **非对称骨干**：RGB 侧用 SAM2 冻住保先验，Thermal 侧 ConvNeXt 全训适配模态差异——一个提供稳定特征，一个灵活适应
2. **两个模态各自独立预测**，再根据置信度融合——如果 RGB 和 Thermal 都说某像素是"车"，那大概率对；不一致的时候才需要额外处理
3. **分歧细化**：就是针对 RGB 和 Thermal "吵架"的区域，用一个可学习的 gate 做残差修正。直觉是——两模态一致的地方不需要动，不一致的地方才值得多看

训练 loss 三部分：10% 密集标注做 CE + 无标签部分用 teacher 打伪标签（置信度 ≥0.8 才用）+ 点标注给一个很弱的 CE（λ=0.2），主要是告诉模型"这张图里有这个类别"。

## 效果怎么样

**r10 主结果**：test strict mIoU **60.59**

作为参照：
- RGB-only（同样 r10 协议）：58.09
- Thermal-only：51.72
- 融合比单模态高出一截

**r20** 能到 **61.48**，标注翻倍涨不到一个点——说明 10% 到 20% 这个区间模型已经在从无标签数据里学了，不纯靠更多标注

**消融几个关键点**：

| 操作 | test mIoU | 掉的点 |
|------|----------:|------:|
| 完整 pipeline | **60.59** | — |
| 去掉 disagreement gate | 58.54 | -2.05 |
| 把融合换成 naive fusion | 55.79 | -4.80 |
| 加 thermal prior injection | 60.53 | 基本打平 |

Disagreement Refinement 是最关键的模块，拿掉直接掉两个点。融合质量是性能底线——用最简单的融合方式直接掉近 5 个点。

## 踩过的坑

试了很多方向，大部分不 work：
- Dual-Branch Co-Training、Point Diffusion、Class-balanced Sampler 都不行
- EMA Soft Consistency 显著低于 baseline（57.09）
- DGR 几何约束不稳定
- MFNet 的外部无标签数据也没帮上忙

总共大概试了七八个方向，最后稳定涨点的就 Disagreement Refinement 和好的融合模块。

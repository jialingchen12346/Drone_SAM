# Condition-Aware Cross-Modal Adaptive Fusion for Drone-View Multimodal Semantic Segmentation

## 摘要

无人机场景下的多模态语义分割同时面临两类关键挑战。第一，飞行姿态、光照和天气变化会导致 RGB 与热红外模态的信息质量在不同场景中动态波动，静态融合策略难以稳定适配。第二，俯视视角会显著压缩目标像素面积，使交通灯、行人、摩托车等小目标在解码过程中更容易被淹没。针对这两个问题，本文提出 **CACAF-HGSOAD** 框架。具体而言，本文设计了 **CACAF (Condition-Aware Cross-Modal Adaptive Fusion)**，通过模态质量评估与跨模态增强实现条件感知的自适应融合；同时设计了 **HGSOAD (Hierarchical Guided Small-Object-Aware Decoder)**，利用分层解码、通道门控和辅助监督增强小目标恢复能力。该框架以冻结的 **SAM2 Hiera-L** 作为 RGB 主干，以全量可训练的 **ConvNeXt-Tiny** 编码热红外模态，在保留基础模型通用表征能力的同时实现面向任务的高效适配。

在 FMB 测试集上，本文方法取得 **68.62 mIoU**，相较 MM SAM-Adapter 的 **66.10** 提升 **+2.52**。统一训练配置下的模块消融进一步验证了方法有效性：去除 CACAF 性能下降 **5.76 mIoU**，去除 SAGU 性能下降 **3.05 mIoU**。损失函数消融表明 **CE + Dice** 优于 **CE + OHEM** 和 **CE + Dice + OHEM**。此外，在严格 **9 类协议** 下，本文方法在 MFNet 上取得 **54.73 mIoU**，与 EGFNet 接近，并优于 MFNet 与 RTFNet 等经典方法。

## 1 引言

多模态语义分割通过融合可见光与辅助模态信息，可以在弱光、遮挡和复杂环境下提升场景理解鲁棒性。对于无人机平台，这一任务更具挑战性。其一，俯视视角显著压缩目标的空间尺度，小目标类别更容易在下采样和解码过程中丢失。其二，无人机飞行高度、拍摄姿态和环境条件持续变化，不同模态的可靠性也随场景而动态变化，固定融合策略往往难以充分利用跨模态互补性。

近年来，基础模型在视觉表征方面展现出强泛化能力。Segment Anything Model (SAM) 及其后续版本 SAM 2 提供了强大的通用视觉特征，而 ViT-Adapter、SAM-Adapter 和 MM SAM-Adapter 则表明，冻结大模型主干并引入轻量适配模块，是将基础模型迁移到下游密集预测任务的一条有效路径。然而，对 FMB 这类无人机 RGB-T 语义分割场景而言，现有方案仍存在两点不足。首先，它们通常缺乏对输入级模态质量差异的显式建模，难以根据当前场景动态调节两种模态的贡献。其次，解码端往往缺少针对小目标恢复的专门设计，容易在高层语义融合后进一步损失细粒度结构。

为解决上述问题，本文提出 **CACAF-HGSOAD**。在编码端，本文采用 **SAM2 Hiera-L + Bottleneck Adapter** 作为 RGB 主干，并使用 **ConvNeXt-Tiny** 编码热红外模态，构建非对称双流架构。在融合端，本文提出 **CACAF**，通过模态质量评估和双向跨模态注意力实现条件感知融合。在解码端，本文提出 **HGSOAD**，通过层级 U-Net 式上采样、**SAGU** 门控和辅助监督增强小目标恢复能力。

本文的主要贡献如下。

1. 提出 **CACAF**，通过模态质量评估和跨模态增强实现条件感知的自适应融合。
2. 提出 **HGSOAD** 与 **SAGU**，针对无人机俯视场景中的小目标恢复问题设计轻量解码增强机制。
3. 在 FMB 测试集上达到 **68.62 mIoU**，相较 MM SAM-Adapter 提升 **+2.52**。
4. 提供统一口径的模块消融和损失函数消融，明确 CACAF、SAGU 及 **CE + Dice** 训练目标的独立作用。

## 2 相关工作

### 2.1 多模态语义分割

RGB-X 语义分割通过引入热红外、深度、事件或 LiDAR 等辅助模态，提升复杂环境下的鲁棒性。早期 RGB-T 方法多采用双分支卷积编码器和显式融合解码器，例如 **MFNet**、**RTFNet** 与 **FuseSeg**，其核心思路是在编码或解码阶段融合 RGB 与热红外特征。这类方法奠定了 RGB-T 语义分割的基本范式，但对跨模态交互的建模能力仍然有限。

随后，研究重点逐步转向更强的跨模态对齐和特征交互。代表性方法包括 **FEANet**、**GMNet**、**DooDLeNet** 和 **CRM** 等，它们分别从边界增强、门控融合、差异建模或随机掩码学习等角度提升模态互补性。与此同时，Transformer 框架被引入 RGB-X 语义分割后，**CMX** 通过跨模态 Transformer 进行特征交换，**CMNeXt** 则进一步提出面向 arbitrary-modal 场景的统一分割框架，并在 DeLiVER、MFNet 等基准上取得较强表现。

近期方法继续增强跨模态融合强度与条件建模能力，例如 **GeminiFusion**、**RoadFormer+**、**CAFuser** 和 **StitchFusion** 等。尽管这些方法持续推动了 RGB-X 分割性能，但大多数工作主要面向车载或通用道路场景，针对无人机俯视场景中的模态质量波动与小目标恢复问题仍缺乏专门设计。

### 2.2 基础模型适配与密集预测迁移

基础模型在下游视觉任务中的迁移已成为研究热点。**ViT-Adapter** 表明，在冻结大规模预训练视觉 Transformer 的前提下，引入轻量适配器即可显著增强密集预测性能。**SAM-Adapter** 进一步证明，SAM 在若干原生表现不足的场景中可以通过轻量适配完成有效迁移。沿着这一思路，**MM SAM-Adapter** 将 SAM 主干扩展到多模态语义分割任务，通过多模态融合模块和侧路适配结构，把辅助模态信息注入 RGB 主干特征。

与上述方法相比，本文并不改变“冻结大模型主干 + 轻量适配”的整体范式，而是在此基础上进一步面向无人机场景提出质量感知融合和小目标导向解码两个针对性模块。

### 2.3 无人机场景与小目标分割

与地面视角 RGB-T 分割相比，无人机场景至少存在两点额外困难。首先，俯视视角使大量交通参与体和基础设施目标只占据极少像素，小目标类别更容易在多层下采样后被淹没。其次，无人机在全天候与复杂照明条件下工作时，RGB 与热红外模态的可用性波动更明显，样本级质量差异更大。因此，针对无人机场景的模型不仅需要有效融合多模态信息，还需要在解码阶段显式保留和恢复细粒度结构。本文提出的 CACAF 与 HGSOAD 分别对应解决这两类问题。

## 3 方法

### 3.1 问题定义与设计动机

给定 RGB 图像 $I^{rgb}$、热红外图像 $I^{thm}$ 以及像素级标注 $Y$，目标是学习一个映射
\[
\mathcal{F}:(I^{rgb}, I^{thm}) \mapsto \hat{Y},
\]
其中 $\hat{Y}\in\mathbb{R}^{H\times W\times C}$ 表示 $C$ 类语义分割预测。本文的设计围绕两个核心问题展开：

- **模态质量波动**：不同场景中 RGB 与热红外模态的可靠性并不恒定；
- **小目标易丢失**：无人机俯视场景中目标尺度较小，解码器需要更强的细粒度恢复能力。

### 3.2 整体架构

```
RGB Image  → SAM2 Hiera-L (frozen) + Bottleneck Adapter ──┐
                                                            ├─→ CACAF (4 levels) ─→ HGSOAD ─→ Prediction
Thermal    → ConvNeXt-Tiny (trainable)                    ──┘
```

本文框架由四部分构成：冻结的 RGB 主干、可训练的热红外编码器、多尺度 CACAF 融合模块以及 HGSOAD 解码器。对 $512\times512$ 输入，两个编码器输出的 4 级特征尺寸分别如下。

| Level | SAM2 Hiera-L | ConvNeXt-Tiny | Stride |
|---|---|---|---|
| f1 | [B, 144, 128, 128] | [B, 96, 128, 128] | 4 |
| f2 | [B, 288, 64, 64] | [B, 192, 64, 64] | 8 |
| f3 | [B, 576, 32, 32] | [B, 384, 32, 32] | 16 |
| f4 | [B, 1152, 16, 16] | [B, 768, 16, 16] | 32 |

该模型总参数量约为 **263.7M**，其中可训练参数约 **51.6M**。如图 1 所示，本文整体框架遵循“强主干表征 + 轻量任务适配 + 分层跨模态融合”的设计思路。RGB 分支使用冻结的 SAM2 Hiera-L 作为主要语义表征来源，以保留基础模型的大规模预训练知识；热红外分支则采用全量可训练的 ConvNeXt-Tiny，以增强模型对低照度、遮挡和成像退化条件的适应性。两路特征在四个尺度上分别进入 CACAF 进行条件感知融合，随后由 HGSOAD 自顶向下逐级恢复空间细节。这种非对称双编码器结构一方面避免了对大模型主干的高成本微调，另一方面也使辅助模态可以围绕当前任务进行更充分的可塑性学习。

### 3.3 RGB 编码器：SAM2 Hiera-L with Bottleneck Adapter

本文使用 SAM2 Hiera-L 作为 RGB 主干，并冻结其原始骨干参数，仅训练插入在各个 Hiera block 前的 Bottleneck Adapter。设输入 token 为 $x$，Adapter 输出为
\[
\mathrm{Adapter}(x)=W_2(\mathrm{GELU}(W_1 x)),
\]
则进入原始 block 的特征为 $x+\mathrm{Adapter}(x)$。这种做法继承了基础模型的通用表征能力，同时避免全量微调带来的高训练成本。

### 3.4 热红外编码器：ConvNeXt-Tiny

热红外分支采用 `timm` 提供的 **ConvNeXt-Tiny**，提取 4 级多尺度特征。该分支全量参与训练，用于补充 RGB 主干在弱光、遮挡或低对比度条件下的缺失信息。与冻结的 SAM2 主干相比，该设计形成“强 RGB 主干 + 可塑辅助分支”的非对称多模态结构。

### 3.5 CACAF：条件感知跨模态自适应融合

对于第 $i$ 个尺度的 RGB 特征 $f_i^{rgb}$ 和热红外特征 $f_i^{thm}$，CACAF 包含四个步骤。

1. **通道对齐**
\[
\hat{f}_i^{rgb}=\psi_i^{rgb}(f_i^{rgb}), \quad \hat{f}_i^{thm}=\psi_i^{thm}(f_i^{thm}),
\]
其中 $\psi$ 为 $1\times1$ 卷积或恒等映射，用于把两个模态对齐到同一通道维度。

2. **模态质量评估**
\[
q_i^{rgb}=\mathrm{MLP}(\mathrm{GAP}(\hat{f}_i^{rgb})), \quad
q_i^{thm}=\mathrm{MLP}(\mathrm{GAP}(\hat{f}_i^{thm})),
\]
随后通过 softmax 得到归一化融合权重
\[
[w_i^{rgb}, w_i^{thm}] = \mathrm{softmax}([q_i^{rgb}, q_i^{thm}]).
\]

3. **跨模态增强**

对高分辨率的 `f1` 层，由于空间大小为 $128\times128$，token 数达到 16K，直接执行跨模态注意力的计算代价过高，因此本文仅保留质量加权而不在该层引入 cross-attention。对 `f2/f3/f4` 三层，则采用双向多头注意力进行跨模态增强，并在注意力前使用 LayerNorm 以提升训练稳定性。

4. **自适应融合**
\[
f_i^{fused}=w_i^{rgb}\tilde{f}_i^{rgb}+w_i^{thm}\tilde{f}_i^{thm},
\]
其中 $\tilde{f}_i^{rgb}$ 和 $\tilde{f}_i^{thm}$ 为跨模态增强后的特征。

CACAF 的核心思想是：不再对两个模态采用固定或隐式学习的静态融合系数，而是在每个样本、每个尺度上显式估计模态质量，并据此动态调整融合贡献。图 2 进一步展示了 CACAF 的内部流程。可以看到，该模块并不是简单地对两路特征做拼接或平均，而是首先通过通道对齐建立统一嵌入空间，再利用轻量 MQA 分支预测模态质量权重，并在计算可承受的尺度上通过双向 cross-attention 实现显式的信息交换。特别地，最高分辨率的 `f1` 层仅保留质量加权而跳过 cross-attention，这一设计直接来源于其 16K token 带来的计算开销约束；而在 `f2/f3/f4` 三层中，引入跨模态增强则有助于让 RGB 与热红外在语义上互相补充。最终的加权融合输出既保留了高质量模态的主导信息，又避免了固定融合策略在复杂场景中的失配问题。

### 3.6 HGSOAD：层级引导小目标感知解码

HGSOAD 采用 U-Net 风格的自顶向下层级解码结构。首先通过 $1\times1$ 卷积把 4 个尺度统一到相同解码通道数，再通过逐级上采样和 skip connection 恢复空间分辨率。

在每个尺度上，HGSOAD 通过 **SAGU** 执行轻量通道门控。SAGU 同时利用全局平均池化和全局最大池化信息：
\[
g_i=\sigma\left(\phi(\mathrm{GAP}(x_i))+\phi(\mathrm{GMP}(x_i))\right),
\]
\[
\hat{x}_i = g_i \odot x_i,
\]
其中 $\phi$ 表示 `1x1 Conv -> ReLU -> 1x1 Conv`。这种门控形式比单一路径的通道注意力更适合强调局部显著响应，对小目标类别尤其有利。此外，HGSOAD 在中间解码层 `d2` 和 `d3` 上引入辅助监督头，以缓解深层语义主导下的浅层细节衰减问题。

### 3.7 训练目标

本文采用 **主头 + 辅助头的 CE + Dice** 作为训练目标：
\[
\mathcal{L}=\mathcal{L}_{main} + \lambda \left(\mathcal{L}_{aux2}+\mathcal{L}_{aux3}\right),
\]
其中
\[
\mathcal{L}_{main}=\mathcal{L}_{CE}(p,y)+\mathcal{L}_{Dice}(p,y),
\]
\[
\mathcal{L}_{auxk}=\mathcal{L}_{CE}(p_k^{aux},y)+\mathcal{L}_{Dice}(p_k^{aux},y), \quad k\in\{2,3\},
\]
并设置 $\lambda=0.4$。实验表明，Dice 与 OHEM 同时使用会导致性能下降，因此最终主结果采用 **CE + Dice**。

## 4 实验

### 4.1 数据集与评测协议

#### FMB

FMB 是一个面向真实复杂环境的 RGB-T 语义分割基准，包含 **14** 个语义类别和 `1060/160/280` 的 `train/val/test` 划分，原始测试分辨率为 `800×600`。训练阶段使用随机缩放、随机裁剪后的 `512×512` 输入；主结果评测则在原始测试分辨率下进行，仅在推理前将图像 pad 到 32 的整数倍，而不对整图强制缩放到 `512×512`。

#### MFNet

MFNet 作为跨数据集补充实验，用于验证方法在另一 RGB-T 分割基准上的表现。本文在严格 **9 类协议** 下报告结果，以避免由类别口径不一致带来的性能高估。

#### 指标

本文主要报告 **mIoU**、**mAcc** 和 **aAcc**，其中 **mIoU** 为主指标。

### 4.2 实现细节

FMB 主结果的训练配置如下。优化器采用 AdamW，SAM2 Adapter 与 ConvNeXt-Tiny 的学习率均设为 `1e-4`，CACAF 与 HGSOAD 的学习率设为 `2e-4`，权重衰减为 `0.01`。学习率调度采用 `500` iter warmup 加 cosine decay。模型在 `BF16` 混合精度下训练 `60` 个 epoch，batch size 为 `4`。数据增强包括随机缩放、随机裁剪、随机水平翻转、Gaussian blur(`p=0.2`)、photometric distortion 以及 `cat_max_ratio=0.75` 约束；训练和验证阶段均采用 `letterbox` resize 策略。

### 4.3 与现有方法对比（FMB Test）

表 1 给出了本文方法与直接基线 **MM SAM-Adapter** 在 FMB 测试集上的对比结果。

| Method | Backbone | mIoU | mAcc | aAcc |
|---|---|---:|---:|---:|
| MM SAM-Adapter | SAM ViT-L | 66.10 | 72.09 | 93.95 |
| **Ours (CACAF-HGSOAD)** | **SAM2 Hiera-L** | **68.62** | **75.76** | **93.27** |

相较基线，本文在 FMB 测试集实现 **+2.52 mIoU** 与 **+3.67 mAcc** 提升。虽然 aAcc 略低于基线，但本文方法在少样本小目标类别上的提升更显著，说明性能增益主要来自对困难类别和细粒度结构的更好恢复，而非对大面积主导类别的保守拟合。

### 4.4 模块消融

表 2 给出了统一 **CE + Dice** 训练配置下的模块消融结果。

| Method | Test mIoU | Δ |
|---|---:|---:|
| **Full (CACAF + SAGU)** | **68.62** | — |
| w/o CACAF | 62.86 | -5.76 |
| w/o SAGU | 65.57 | -3.05 |
| w/o CACAF, w/o SAGU | 64.78 | -3.84 |

结果表明，**CACAF 是主要性能来源**，去除后性能下降最为明显；**SAGU** 也能在完整框架中带来稳定增益，说明解码端的小目标增强是必要的。值得注意的是，`w/o CACAF, w/o SAGU` 虽然优于仅移除 CACAF 的情形，但仍明显落后于完整模型，说明 CACAF 与 SAGU 并非简单叠加，而是在高质量融合特征上存在明显协同作用。

### 4.5 损失函数消融

表 3 给出了完整模型在不同损失函数组合下的结果。

| Loss | mIoU | mAcc | aAcc | ΔmIoU |
|---|---:|---:|---:|---:|
| **CE + Dice** | **68.62** | **75.76** | 93.27 | — |
| CE + OHEM | 67.79 | 74.70 | 93.58 | -0.83 |
| CE + Dice + OHEM | 66.79 | 72.89 | 93.46 | -1.83 |

这一结果表明，在本文网络结构下，Dice 与 OHEM 的组合并未形成有效互补，反而会带来性能退化。因此，本文最终主模型采用 **CE + Dice** 作为训练目标。

### 4.6 跨数据集补充实验（MFNet）

为进一步考察方法的跨数据集适应能力，本文在 MFNet 上进行了补充实验，并统一采用严格 **9 类评测协议** 报告结果。

| Method | mIoU |
|---|---:|
| MFNet (2017) | 45.1 |
| RTFNet (2019) | 53.2 |
| EGFNet (2022) | 54.8 |
| GMNet (2021) | 57.3 |
| **Ours (CACAF-HGSOAD)** | **54.73** |

在该协议下，本文方法取得 **54.73 mIoU**、**68.14 mAcc** 和 **97.90 aAcc**。与经典的 MFNet 和 RTFNet 相比，本文方法表现更优；与 EGFNet 相比结果接近；与 GMNet 相比仍有差距。这说明本文方法在跨数据集迁移上具备一定适应能力，但其优势主要仍体现在 FMB 无人机场景。

## 5 讨论

### 5.1 为什么质量感知融合对无人机场景重要

与固定地面视角场景不同，无人机拍摄时的光照、视角和成像距离变化更频繁，RGB 与热红外模态的有效性也更不稳定。CACAF 通过显式质量估计和动态加权，使得融合策略可以随输入样本变化而调整，从而更适合无人机场景。

### 5.2 为什么小目标导向解码是必要的

FMB 中多类关键目标在俯视视角下仅占据少量像素。单纯依靠高层融合特征并不足以稳定恢复这些细粒度结构。HGSOAD 通过层级解码、SAGU 门控和辅助监督增强浅层细节传播，因此对交通灯、公交、摩托车等类别更有帮助。

### 5.3 局限性

尽管本文方法在 FMB 上取得了稳定增益，但仍存在若干局限。首先，当前验证主要集中在 FMB 及补充性的 MFNet 实验，跨更多 RGB-T 基准的泛化能力仍需进一步系统评估。其次，本文尚未对参数效率、推理延迟和吞吐量进行完整分析，因此在实际部署层面的成本收益权衡仍有待补充。最后，实验中观察到跨硬件训练会带来一定性能漂移，这提示后续工作需要更系统地研究训练环境对多模态适配结果的影响。

## 6 结论

本文提出 **CACAF-HGSOAD**，用于无人机视角 RGB-T 语义分割。该方法在保持“冻结基础模型主干 + 轻量适配”范式的同时，引入条件感知跨模态融合和小目标导向解码机制。在 FMB 测试集上，本文方法达到 **68.62 mIoU**，相较 MM SAM-Adapter 提升 **+2.52**；统一口径的模块消融验证了 CACAF 与 SAGU 的有效性；损失函数消融进一步确认 **CE + Dice** 为当前结构下更合适的训练目标。补充性的 MFNet 实验则表明，该方法在跨数据集设置下也具有一定适应能力。总体而言，本文结果说明，在基础模型适配框架中引入条件感知融合与小目标导向解码，是提升无人机多模态语义分割性能的一条有效路径。

这个观察非常准确，而且指向了当前方案一个根本性的问题。

  ---
  问题的本质：模型和训练策略完全解耦

  当前的结构是这样的：

  [全监督融合模型]  ←── 完全不知道自己在用多少标注
          ↑
  [label-efficient 训练策略]  ←── EMA伪标签、point loss、阈值过滤

  所有标注效率的增益（+3.25 point，+0.51 semi）全部来自训练策略，模型结构本身对"我只有 10%
  标注"这件事完全无感知。

  这在科研上是一个弱点：

  - 审稿人会问：你的模型改进和 label efficiency 的关系是什么？为什么不直接用任何一个全监督模型 +
  你的训练策略？
  -
  你的回答现在只能是：我们的融合模型比基线好，然后再加训练策略。这两个贡献是独立的，不是相互强化的。

  ---
  真正的问题：什么叫"为标注效率设计的架构"

  全监督融合模型的设计目标是：用完整标注训练时，融合两模态特征效果最好。

  标注效率导向的架构设计目标应该是：在标注稀缺时，模型本身能产生更可靠的自监督信号，或者让稀疏标注的
  监督效果传播更广。

  这两个目标是不同的。

  ---
  架构层面可以做什么

  设计 1：双路预测头——让架构自己产生可靠性估计

  RGB特征 ──┐
             ├── Fusion → 主预测头 → 主预测
  Thermal特征──┘

  RGB特征 ─────────→ RGB独立预测头 → pred_rgb
  Thermal特征 ──────→ Thm独立预测头 → pred_thm

  可靠性 = agreement(pred_rgb, pred_thm)

  这不只是训练策略——双路预测头是架构的一部分。模型被迫学习两个模态各自能解释什么，agreement
  是从结构中涌现出来的，而不是外部强加的阈值。

  全监督阶段：三个头都受 GT 监督，互相约束
  半监督阶段：agreement 自动成为伪标签质量估计

  关键：这个设计让"模态一致性"从训练 trick 变成了模型的结构性输出。

  ---
  设计 2：原型记忆——让少量精标注的信息传播到整个训练过程

  精标注样本 → 提取类别原型 → 原型记忆库 [C, D]
                                      ↓
  无标注样本 → 特征 → 与原型计算相似度 → 类别归属概率
                                      ↓
                              辅助伪标签 / 损失权重

  当前模型没有任何机制让 10% 精标注的语义信息"扩散"到 90% 无标注样本的学习过程中——除了 EMA teacher
  本身（而 teacher 在早期也只在 10% 数据上训练过）。

  原型记忆库把精标注的类别语义显式地存下来，作为无标注区域的参照。这是一个为低标注场景设计的结构，在
  全监督场景下这个组件基本是多余的。

  ---
  设计 3：Point 扩散机制——让稀疏弱监督信号在结构上传播

  当前 point loss 只作用在点的坐标位置，一个点的梯度只更新那一个像素的预测。

  当前：point(x, y, cls) → CE loss at (x, y) only

  一个结构性的改进：

  point(x, y, cls) → 以(x,y)为查询，在特征图上做相似度检索
                   → 找到语义相似的邻域区域
                   → 这些区域也应该是同一类别
                   → 用这个"扩散后的 mask"来监督

  这需要模型有一个特征亲和力模块（affinity）——计算像素间的语义相似度，让 point
  信号自然传播到周围同类区域。

  这是为弱监督专门设计的架构组件，在全监督场景下没有意义（因为你有完整 GT）。
